# The New Witness

A truth archive, resistance tracker, and emotional memory engine.

Copyright (c) 2026 Haley Ann Bird. All Rights Reserved.

## Overview

The New Witness is a system for documenting and preserving truth in the face of erasure. It functions as:

- **Truth Archive** — Preserving verifiable records and primary sources
- **Resistance Tracker** — Monitoring and documenting resistance movements and actions
- **Emotional Memory Engine** — Capturing the human experience behind events that institutional records often flatten
